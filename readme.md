# Maila's General Merchandise — Inventory V2

## Included
- Login page
- Dashboard
- Inventory management
- Low-stock alerts
- Sales / transactions
- Automatic 20% markup price
- Printable receipt
- Responsive layout
- Original Excel inventory data and logo
- Browser persistence

## Important database note
This packaged version is a **working standalone prototype**: its data is stored in the browser's local storage. That means each device has its own data.

For true multi-device access, deploy a shared backend/database (for example Supabase or Firebase) and replace the localStorage layer with authenticated database reads/writes. The UI and workflows are already prepared for that upgrade.
